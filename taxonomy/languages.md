# Language Annotation Guidance

- Prefer BCP 47 tags (for example, `en-NG`, `sw-KE`, `pt-MZ`, `ha-NG`) when the language and region are supported by the evidence.
- Do not infer language from country or country from language.
- Record code-switching where multiple languages are meaningfully used. A language tag does not imply that the entire message is in that language.
- Record script and transliteration only when relevant and known.
- Distinguish translation from original content. A translation is not a verbatim source.
- Identify dialect or sociolect only when a qualified reviewer supports the label; avoid overclaiming.
- Store contributor expertise and review notes in PR discussion, not as personal data in the published record.
- If language is uncertain, use an explicit unknown/undetermined value rather than guessing.
